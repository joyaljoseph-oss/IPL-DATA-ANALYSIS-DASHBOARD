# 🏏 IPL Analytics Dashboard

## 1. Project Title 

**🏏 IPL Analytics: Interactive Cricket Performance Dashboard**

An interactive data visualization dashboard designed to explore Indian Premier League (IPL) cricket statistics, team performance, match outcomes, and player achievements through data-driven insights.

## 2. Short Description 

The **IPL Analytics Dashboard** is a data analytics project that transforms cricket statistics into meaningful visual insights. It helps users explore team performance, analyze match results, compare player contributions, and identify trends across IPL matches, supporting a deeper understanding of the tournament through data visualization.

## 3. Tech Stack

- **📊 Microsoft Power BI** – Dashboard development and interactive visualizations.
- **📂 Microsoft Excel / CSV** – Data storage and preparation, depending on the source format.
- **🔄 Power Query** – Data cleaning and transformation, if used.
- **🧠 DAX** – Calculated measures and KPIs, if used.
- **📁 File Formats** – `.pbix` for the Power BI dashboard and image files for previews.

## 4. Data Source

**Source:** IPL match and player statistics dataset.

The dataset may include match details, teams, venues, match results, player performances, and other tournament statistics, depending on the data available in the project.

## 5. Features 

### Business Problem

Cricket tournaments generate large amounts of data, making it difficult to compare team performance, evaluate individual contributions, and identify match trends by examining raw statistics alone.

### Goal of the Dashboard

The goal is to convert IPL data into clear and interactive visualizations that make cricket statistics easier to explore and understand.

### Walkthrough of Key Visuals

- **Key Performance Indicators (KPIs):** Display important tournament statistics available in the dataset.
- **Team Performance Analysis:** Compare teams based on available match statistics and results.
- **Player Performance:** Explore individual player contributions using relevant batting or bowling metrics.
- **Match Results Analysis:** Understand match outcomes and winning patterns.
- **Venue Analysis:** Explore match distribution and performance across venues, if included.
- **Interactive Filters:** Filter the dashboard by teams, seasons, players, or other available categories.

### Business Impact & Insights

- **Performance Comparison:** Helps compare teams and players using statistical evidence.
- **Trend Identification:** Makes it easier to identify patterns across matches and seasons.
- **Player Evaluation:** Supports analysis of individual contributions.
- **Data Storytelling:** Presents cricket statistics in a visually engaging and understandable format.
